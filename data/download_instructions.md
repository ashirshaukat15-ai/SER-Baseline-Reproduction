# Dataset Download Instructions

The raw audio files are **not** uploaded to this repository due to file size limits. 

1. Download the **RAVDESS Emotional Speech Audio** dataset from Kaggle: 
   https://www.kaggle.com/datasets/uwrfkaggler/ravdess-emotional-speech-audio
2. Extract the downloaded `.zip` file.
3. Place the extracted folder named `audio_speech_actors_01-24` in the root directory of this project (next to the `src` folder).
4. Ensure the folder structure looks like this:
   - `SER-Baseline-Reproduction/`
     - `audio_speech_actors_01-24/`
     - `src/`
     - `requirements.txt`
